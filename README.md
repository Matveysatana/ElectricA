# Лендинг «Артур Алипов — электромонтаж»

React + TypeScript + Vite лендинг с Tailwind CSS и небольшим слоем авторских CSS-стилей. Контент вынесен в `src/content.ts`.

## Запуск

```powershell
npm install
npm run dev
```

После запуска **не закрывайте это окно PowerShell**: Vite работает, пока запущена команда. Откройте адрес, который выведет терминал — в этом проекте он будет [http://127.0.0.1:5173](http://127.0.0.1:5173). Адрес `127.0.0.1` используется вместо `localhost`, чтобы исключить проблемы с разрешением адреса в Windows/браузере.

Если команда сообщает, что `npm` не найдена, установите Node.js LTS и заново откройте PowerShell. Если порт 5173 уже занят, Vite сам выведет другой адрес — открывайте именно его.

Production-сборка:

```powershell
npm run build
```

## Что редактировать перед публикацией

В `src/content.ts` заполните `site`:

- `phone`, `telegramUrl`, `maxUrl`, `email` (и при необходимости `whatsappUrl`);
- `formEndpoint` — настоящий HTTPS endpoint приёма заявок;
- `policyUrl` и юридические сведения;
- подтверждённые опыт, квалификацию, формат работы и преимущества;
- изображения героя/портрета и реальные работы в `portfolio`.

Пока `formEndpoint` пустой, форма валидирует данные, но честно сообщает, что отправка не подключена. Она не имитирует успешную заявку.

## Прайс-лист

Страницы [`/prices`](/prices) и [`/price`](/price) уже доступны из меню и ведут на один прайс-лист. Заполните массив `priceCategories` в `src/content.ts` только утверждёнными позициями и ценами. До этого сайт показывает корректное состояние «Прайс уточняется» и не подставляет придуманные расценки.

## Публикация

После `npm run build` разверните содержимое папки `dist` на статическом хостинге. Для SPA настройте fallback на `index.html` при необходимости. До публикации подключите политику обработки персональных данных и работающий защищённый серверный endpoint с антиспам-проверкой (например, honeypot/rate limit/Turnstile на сервере).
